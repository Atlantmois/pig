# Fictional ecosystem

All components listed here are currently fictional unless explicitly stated otherwise. These are ideas and documentation, not downloads or production software.

```text
PIG Project
├── pig-kernel
├── pigsh
├── PigFS
├── piglet
└── Pigora
```

- **pig-kernel:** A kernel for pigs. Currently fictional; there is no kernel architecture to install.
- **pigsh:** A shell in which `pig@barn:~$ oink` seems reasonable.
- **PigFS:** A file system drawn on paper for now:

  ```text
  /
  ├── barn
  ├── mud
  ├── pasture
  └── trough
  ```

  Mud is a perfectly acceptable working environment.

- **piglet:** A package manager in the fiction. `piglet install snacks` is an example, not a working command.
- **Pigora:** A fictional distribution. It has no relation to Fedora. Please do not install it on production servers.

If one of these becomes a real experiment, its documentation should say exactly what works and what remains fictional.
