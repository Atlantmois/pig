# Terminology

| Term | Meaning |
| --- | --- |
| **PIG** | Pig Isn't GNU; this independent fictional open-source culture project. |
| **Pig** | The 🐖 mascot, or a PIG idea in context. |
| **General PIG License** | An original parody license text, not a vetted software license. |
| **Source Genome** | Playful name for the material needed to study or modify a Pig. |
| **Copigleft** | A playful name for the impulse to share improvements; not a legal mechanism. |
| **pig-kernel** | A kernel for pigs. Currently fictional. |
| **pigsh** | A fictional PIG shell. |
| **PigFS** | A fictional file system with barn, mud, pasture, and trough. |
| **piglet** | A fictional package manager. |
| **Pigora** | A fictional distribution; no relation to Fedora. |
| **Free Swine Software** | A joking label for the project's free software inspiration, not an organization. |

This terminology is not ISO certified.
