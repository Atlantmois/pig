# Mascot assets

The PIG mascot is **🐖**, Unicode **U+1F416 PIG**. The README uses the Unicode character directly. No third-party image file is bundled at present, so there is no asset-specific license or attribution file to include yet.

If a rendered image is needed later, the preferred source is the U+1F416 artwork in [Google's Noto Emoji project](https://github.com/googlefonts/noto-emoji). Verify the current upstream license, include the applicable license text and attribution, and state that the artwork is a rendering of the PIG mascot, not an official Google mascot. Do not use a screenshot of a system emoji or combine the pig with a Google logo.
