## English

### What is PIG?

**PIG** stands for **Pig Isn't GNU**.

PIG is a fictional open-source software culture project inspired by recursive acronyms, Unix hacker culture, free software history, and an unreasonable amount of pig-related terminology.

```text
GNU = GNU's Not Unix
PIG = Pig Isn't GNU
```

It is not an operating system. It is not GNU. It is, however, a pig.

### Why PIG?

Recursive acronyms are fun, and open-source culture can afford a little dry humor. PIG is both parody and homage, not an anti-GNU project. It is a place for documentation, a fictional software ecosystem, and perhaps a few small experimental tools.

> GNU's Not Unix.
>
> PIG Isn't GNU.

### The Pig

PIG is represented by **🐖 (U+1F416 PIG)**. It's a pig. That's enough.

The mascot is lazy, hungry, and deeply suspicious of unnecessary complexity. It prefers simple tools, short dependency lists, good snacks, and the occasional nap. Here, laziness is an engineering principle: do less work that does not need doing, without lowering the quality of work that does.

> Do less. Keep it simple. Eat something. Maybe take a nap.

See the short [mascot guide](docs/mascot.md) for its voice and boundaries.

### The fictional ecosystem

`pig-kernel`, `pigsh`, `PigFS`, `piglet`, and `Pigora` are currently fictional concepts, not available software. [Explore the ecosystem](docs/ecosystem.md) or its [terminology](docs/terminology.md).

### Project status

> **The Pig Exists.**

PIG is currently a cultural, documentation, and experimental project. The immediate work is to establish its identity and visual style, document the fictional ecosystem, collect good ideas, and make small tools only when they earn their place. Creating another operating system is not on the list.

Read the [philosophy](PHILOSOPHY.md), [roadmap](ROADMAP.md), and [contribution guide](CONTRIBUTING.md).

### About the General PIG License

The [General PIG License v0.1](LICENSE) is an original parody and a cultural artifact. It has not been legally reviewed or approved by the OSI or FSF. **Do not assume it is suitable for licensing serious software.** If this repository gains real software, that code can receive a conventional, reviewed open-source license separately. Third-party assets retain their own licenses; see [asset notes](assets/README.md). It calls source code *Source Genome* and copyleft *Copigleft*. This terminology is not ISO certified.

### FAQ

**Is PIG an operating system?** No.

**Will it become one?** That would be an unfortunate escalation.

**Is PIG part of GNU or anti-GNU?** Neither. It is an independent parody and homage inspired by GNU, Unix, and free software culture.

**Is the General PIG License a real software license?** It is a real text file. Whether you should license serious software under it is another question.

## 中文

### PIG 是什么？

**PIG** 是 **Pig Isn't GNU** 的缩写。

PIG 是一个虚构的开源文化项目，灵感来自递归缩写、Unix 黑客文化、自由软件历史，以及多得有些不合理的猪相关术语。

```text
GNU = GNU's Not Unix
PIG = Pig Isn't GNU
```

它不是操作系统。它不是 GNU。但它确实是一头猪。

### 为什么是 PIG？

递归缩写很有趣，开源文化也可以保留一点冷幽默。PIG 既是戏仿，也是致意，并不反对 GNU。这里可以写文档、整理虚构软件生态，也许还会出现几个小型实验工具。

> GNU's Not Unix.
>
> PIG Isn't GNU.

### 这头猪

PIG 的代表是 **🐖（U+1F416 PIG）**。它是一头猪。这就够了。

它有点懒，有点贪吃，而且对没有必要的复杂度保持高度警惕。它喜欢简单的工具、短一点的依赖列表、好吃的东西，以及偶尔睡一觉。在这里，懒也是一种工程原则：少做没有必要的工作，但不降低必要工作的质量。

> 少做一点。保持简单。吃点东西。也许睡一觉。

关于它如何说话，以及哪些玩笑应当收敛，见简短的 [mascot 指南](docs/mascot.md)。

### 虚构生态

`pig-kernel`、`pigsh`、`PigFS`、`piglet` 和 `Pigora` 目前都只是虚构概念，并非可用软件。详见[生态说明](docs/ecosystem.md)和[术语表](docs/terminology.md)。

### 项目状态

> **The Pig Exists.**

PIG 目前是一个文化、文档和实验项目。眼下要做的是确定项目身份与视觉形象、整理虚构生态、收集好点子，并且只在确有必要时制作小工具。再造一个操作系统不在计划内。

也可以阅读[项目理念](PHILOSOPHY.md)、[路线图](ROADMAP.md)和[贡献指南](CONTRIBUTING.md)。
