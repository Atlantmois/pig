# Code of Conduct

PIG welcomes contributors and readers with different backgrounds and levels of experience. Treat people with respect, assume good faith where reasonable, and criticize ideas and changes constructively.

Harassment, discrimination, threats, personal attacks, and repeated disruption are not welcome. Humor about software is fine; humor at a contributor's expense is not.

If a discussion becomes uncomfortable or unsafe, contact the repository maintainers through a private channel listed on the repository host. Maintainers may moderate, close, or remove contributions and restrict participation to protect the community. They should explain decisions when doing so is safe and practical.

This code applies to project spaces and to public behavior when someone is representing PIG.
