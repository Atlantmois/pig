# Roadmap

This is a direction for the fictional project, not a release promise. A phase can stay unfinished if its remaining work is unnecessary.

## Phase 0 — The Pig Exists

- Establish the repository structure and project identity.
- Write the philosophy and terminology.
- Define a simple visual identity around 🐖.

## Phase 1 — The Pig Learns to Oink

- Refine mascot assets if a clear need arises.
- Consider a small website.
- Improve documentation and welcome community contributions.

## Phase 2 — The Pig Discovers Unix

- Try small CLI tools, joke utilities, and fake man pages.
- Keep each experiment understandable on its own.

## Phase 3 — Probably a Bad Idea

- Sketch a mock package manager or fictional distribution.
- Reconsider increasingly unnecessary infrastructure before building it.

**Choose the simpler pig.**
